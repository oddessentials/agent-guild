# Provider icons

Drop an SVG named after a provider id (for example `anthropic.svg`) into this
folder and the page shows it, in every skin, instead of the skin's tool icon
or the lettered badge. A provider in `providers.json` can also point `icon` at
any URL path the manager serves.

The Professional skin's Claude Code, Codex CLI, Antigravity CLI and Grok
Build icons carry vendor marks from `@lobehub/icons-static-svg` (MIT); its
Docker Agent and Shell icons are drawn for it. If you add a vendor logo,
follow that vendor's brand guidelines.
